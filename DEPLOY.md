# Запуск демо по IP на AlmaLinux

24 сентября 2026 проверен сервер 62.169.27.185: Docker 29, Compose v2, git установлены. TCP-порт 8095 не занят; каталог /opt/yvnbet отсутствует. Это проверка на момент подготовки: повторите проверку перед запуском. Внешняя доступность проверяется после запуска контейнера.

## Первый запуск

В SSH-сеансе сервера:

```sh
ss -ltn 'sport = :8095'
```

В выводе должна быть только строка заголовков, без LISTEN на 8095. Затем:

```sh
git clone https://github.com/gagikabovyan98/yvnbet.git /opt/yvnbet
cd /opt/yvnbet
cp .env.example .env
docker compose up -d --build
firewall-cmd --zone=public --add-port=8095/tcp
firewall-cmd --permanent --zone=public --add-port=8095/tcp
docker compose ps
curl -f http://127.0.0.1:8095/api/content
```

Ожидается состояние контейнера `Up (healthy)` (healthcheck может занять до 30 секунд). Внешний адрес: http://62.169.27.185:8095 . Админка: http://62.169.27.185:8095/admin . Это временное демо по HTTP; для рабочего сайта следующий этап — домен и HTTPS.

Получить созданные при первом запуске данные администратора:

```sh
cd /opt/yvnbet
docker compose exec web cat /app/data/admin-access.txt
```

Логин `admin`, пароль генерируется автоматически и не хранится в репозитории. Строка localhost в файле относится к внутреннему серверу; для входа используйте внешний адрес выше. Не отправляйте пароль вместе с публичной ссылкой на демо.

## Если 8095 уже занят

Выберите другой свободный TCP-порт через `ss -ltn`. Измените оба значения в `.env`:

```dotenv
YVNBET_PORT=8096
YVNBET_ORIGIN=http://62.169.27.185:8096
```

Откройте выбранный порт вместо 8095 и используйте его в ссылках. PUBLIC_ORIGIN должен совпадать с адресом в браузере, иначе админка отклонит сохранение.

## Обновление

```sh
cd /opt/yvnbet
git pull --ff-only
docker compose up -d --build
```

Контент, загрузки и учётные данные сохраняются в Docker volume `yvnbet-demo_site-data`. Команды обновления не удаляют volume. Не используйте `docker compose down -v`: флаг `-v` удаляет данные.

## Диагностика

```sh
cd /opt/yvnbet
docker compose ps
docker compose logs --tail=100 web
ss -ltn 'sport = :8095'
firewall-cmd --zone=public --query-port=8095/tcp
```

Если локальный curl работает, а внешний адрес недоступен, проверьте также сетевой firewall в панели провайдера. Существующие контейнеры и конфигурация nginx этой инструкцией не изменяются. Compose использует отдельное имя проекта `yvnbet-demo`.
