# YvnBet · сайт и CMS

Каталог игр с тремя языками, управляемыми провайдерами, слайдером, интерактивным львом, акциями, регистрационными заявками и SEO. Проект находится в `yvnbet/`.

## Локальный запуск

Node.js 22.13+ (рекомендуется 24 LTS):

```sh
cd yvnbet
npm ci
npm run build
npm start
```

Сайт: http://localhost:4173/ru · CMS: http://localhost:4173/admin

Для **новой** базы перед первым запуском задайте секретный `ADMIN_PASSWORD` длиной от 12 символов. Он используется один раз для создания пользователя `admin`, в базе хранится только scrypt-хеш. При наличии старого `data/auth.json` прежний пароль переносится автоматически. Значение переменной не меняет пароль существующего пользователя.

```sh
read -s 'ADMIN_PASSWORD?Первый пароль администратора: '
export ADMIN_PASSWORD
npm start
```

Команда чтения пароля выше для zsh/macOS; в bash используйте `read -s -p 'Первый пароль администратора: ' ADMIN_PASSWORD`.

`npm run dev` запускает разработку. `npm test` запускает проверки (предварительно выполните сборку).

Инструкция по CMS, данным и ограничениям: [README приложения](yvnbet/README.md). Размещение на сервере — отдельный этап: [DEPLOY.md](DEPLOY.md).
