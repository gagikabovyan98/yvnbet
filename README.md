# YvnBet

Демонстрационный одностраничный сайт с админ-панелью.

Приложение находится в `yvnbet/`. Подробности и ограничения демо: [README приложения](yvnbet/README.md).

## Локальный запуск

```sh
cd yvnbet
npm ci
npm run build
npm start
```

Сайт: http://localhost:4173 · Админка: http://localhost:4173/admin

Логин администратора — `admin`. Случайный пароль создаётся при первом запуске и сохраняется локально в `yvnbet/data/admin-access.txt`. Пароли, загруженные файлы и изменённый контент не включаются в Git.
