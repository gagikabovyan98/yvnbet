# YvnBet CMS v2

Локальная версия по новому ТЗ от 1 октября 2026 года. React 19 + Express 5 + SQLite, серверная HTML-отрисовка для SEO, сборка Vite.

## Что реализовано

- RU / HY / EN на отдельных адресах `/ru`, `/hy`, `/en`; переключение языка сохраняет страницу.
- Главная, каталог с поиском и фильтрами провайдера/категории, страницы игр, провайдеров, акций, FAQ, произвольные текстовые страницы и приложение.
- Слайдер: автопрокрутка, стрелки, точки, пауза, остановка при фокусе/наведении, поддержка reduced motion.
- Кликабельный лев с анимацией выбирает три разные игры (или меньше, если каталог небольшой). Замена изображения льва в настройках.
- Регистрация: имя, телефон, Telegram, согласие; сохранение заявки, затем переход в Telegram с черновиком. Сообщение отправляет сам посетитель.
- Первый визит: модальное окно 18+ с блокировкой интерфейса и сохранением выбора; отказ оставляет сайт заблокированным.
- Вход и отдельные игры: iframe либо новая вкладка по настройке. В iframe всегда доступна внешняя ссылка.
- Telegram с анимацией внизу справа; username и сообщение меняются из CMS.
- CMS: CRUD и порядок игр, провайдеров, категорий, слайдов, акций/бонусов/новостей/предложений, FAQ, страниц; все переводы; загрузка изображений; SEO; настройки; заявки; сотрудники; журнал действий.
- Даты акций включают целый последний день UTC; будущие, истёкшие и неопубликованные записи скрыты на сайте.
- SEO: уникальные страницы, Title / Description / Keywords, OG / Twitter, canonical, hreflang, sitemap, robots, JSON-LD; контент присутствует в HTML до запуска JavaScript.

## Работа в CMS

Войдите в `/admin` прежним локальным логином. Новая установка создаёт `admin` из переменной `ADMIN_PASSWORD`; не включайте пароль в Git.

1. Добавьте провайдеров и категории. ID связывает их с играми, slug определяет адрес страницы.
2. Создайте игру, выберите провайдера и категорию, загрузите обложку, заполните три языковых заголовка. Укажите **прямой URL конкретной игры** от провайдера.
3. Выберите встроенное окно или новую вкладку, включите «Опубликовано».
4. Переключателем RU / HY / EN заполните переводы. Изображения и URL общие, тексты — отдельные.
5. Нажмите «Опубликовать». Пока кнопка не нажата, редактор содержит локальные изменения; удаление записи можно отменить перезагрузкой без сохранения.
6. Порядок меняется стрелками вверх/вниз. Нельзя удалить провайдера или категорию, пока на них ссылаются игры: сначала переназначьте или удалите эти игры.
7. SEO основной страницы редактируется в «SEO», SEO игры/провайдера/акции — внутри записи. Пустые SEO-поля используют её заголовок и описание.

При одновременном редактировании CMS отклоняет сохранение устаревшей версии (HTTP 409), чтобы не затереть чужую работу.

Роли:

| Роль | Доступ |
|---|---|
| Администратор | Всё, включая сотрудников и удаление заявок |
| Редактор | Контент, изображения, переводы, SEO, настройки |
| Поддержка | Просмотр заявок и изменение статусов |

Изменение роли/пароля завершает сессии сотрудника. Нельзя удалить себя или убрать последнего администратора.

## Данные и безопасность

`data/` полностью исключён из Git. `cms.sqlite` — контент, сотрудники, заявки, сессии и журнал. Пароли — scrypt с солью, токены сессий — SHA-256. Cookie HttpOnly / SameSite=Strict, Secure при HTTPS. Проверки Origin и CSRF, ограничение попыток входа и заявок, параметризованные SQL-запросы, строгая схема содержимого и URL.

Заявки зашифрованы AES-256-GCM. Ключ берётся из `DATA_ENCRYPTION_KEY` (64 hex-символа) либо генерируется в `data/encryption.key` с правами 0600. **Потеря ключа делает заявки нечитаемыми.** Файловый ключ защищает отдельно украденную БД, но не компрометацию всего сервера; для рабочего размещения ключ следует хранить отдельно от бэкапа БД и передавать секретом окружения.

Загрузки ограничены 4 МБ и 25 млн пикселей, реально декодируются Sharp, очищаются от метаданных, уменьшаются до 1920 px и преобразуются в WebP. SVG из CMS не принимается. Исходный комплектный лев — локальный SVG в исходниках. Публично доступен только каталог изображений; БД и ключ не раздаются.

`PUBLIC_ORIGIN` задаёт фактический адрес браузера; локально разрешены localhost и 127.0.0.1 на выбранном порту. За доверенным reverse proxy можно задать `TRUST_PROXY_HOPS=1`, только если прямой доступ к приложению закрыт. По умолчанию proxy-заголовки IP не доверяются.

Старая база `content.json` не перезаписывается: новая структура начинает с v2-контента. Старый `auth.json` используется только для первоначального переноса хеша администратора. У прежней локальной версии может оставаться `admin-access.txt`; это старый файл выдачи пароля, новая CMS его не создаёт. После сохранения доступа в менеджере паролей удалите этот файл вручную.

## Проверки

```sh
npm run build
npm test
```

Тесты работают с временной БД и проверяют SSR/SEO, динамические коллекции, связи, XSS-экранирование, опасные URL, загрузки, Origin/CSRF, роли, защиту последнего администратора, конфликты редакторов, шифрование заявок, сохранность после перезапуска, выход и блокировку перебора пароля. Реальные заявки не используются.

## Перед рабочим размещением

- Игры сейчас — **превью**, по аналогии с указанным референсом. Названия и изображения демонстрационные. Нужны реальные обложки и точные launch URL от оператора; пока URL пуст, кнопка запуска недоступна. Никакого игрового сервера или приёма платежей этот проект не реализует.
- В проверенном 01.10.2026 публичном ответе `ggplus.pro` нет X-Frame-Options или CSP frame-ancestors. Это не гарантирует встраивание авторизации, игр, third-party cookies и последующих страниц. Нужна проверка с предоставленным оператором тестовым аккаунтом и реальными deep links. Обход ограничений не реализуется.
- Логотип YvnBet взят с предоставленного `yvnbet.cheatmo.de`; лев — заменяемый SVG. Adjarabet при проверке возвращал ограничение доступности по стране, поэтому точное совпадение слайдов не заявляется.
- Политика конфиденциальности и условия — явно обозначенные предварительные тексты; оператор должен предоставить реквизиты, окончательные условия и срок хранения заявок. Автоматический срок удаления не выбран без этих данных, удаление доступно администратору.
- Укажите Telegram, ссылку приложения, реальные акции и SEO-домен. Индексация по умолчанию выключена, sitemap пуст до включения. HTTP-домен для рабочего SEO не принимается; нужен HTTPS.
- Сервер/домен/TLS, резервирование, мониторинг и проверка восстановления выполняются на этапе размещения. Core Web Vitals в реальной сети ещё не измерены; отсутствие ошибок во всех окружениях не гарантируется.

Исходное изображение hero сгенерировано для проекта; обложки игровых категорий — из предоставленных ранее AI-референсов. Баннер сжат примерно с 2 МБ до 97 КБ, обложки 29–70 КБ. Админка загружается отдельным JS-модулем и не включается в начальную загрузку сайта.
