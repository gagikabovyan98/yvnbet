# YvnBet — локальное демонстрационное приложение

## Запуск

Требуется Node.js 22.12+ (проверено на Node.js 26).

```sh
npm ci
npm run build
npm start
```

Сайт: http://localhost:4173 . Админка: http://localhost:4173/admin . Сервер слушает только 127.0.0.1. Для разработки: `npm run dev`.

При первом запуске создаётся случайный пароль администратора. Логин `admin`; пароль находится в `data/admin-access.txt` (только локально, файл не включён в Git). Можно задать ADMIN_PASSWORD до первого запуска. Уже существующие учётные данные эта переменная не меняет.

## Возможности

- Адаптивная страница в тёмно-фиолетовой и золотой палитре.
- Русский, армянский и английский интерфейсы, редактор каждой версии.
- Регистрация: `https://t.me/yvnbet?text=...`, подготовленный текст, отправка только самим пользователем.
- Вход: модальное окно с iframe `https://ggplus.pro`; резервная ссылка для отдельного открытия.
- Админка: тексты всех основных блоков, изображения первого экрана и пяти игр, категории игр, контакт Telegram, бонус и лимиты.
- Загрузка PNG/JPEG/WebP до 4 МБ с проверкой сигнатуры файла.
- Серверное сохранение в `data/content.json`; изображения — в `data/uploads/`.
- Пароль хранится как scrypt-хеш; HttpOnly/SameSite cookie, проверка Origin и ограничение попыток входа.

## Проверено

`npm test` — схема содержимого, URL, формат/размер загрузок.
`node server/integration-check.mjs` — вход/выход, запрет записи без сессии, сохранение и восстановление содержимого, загрузка, проверка Origin. Запускается при работающем сервере и использует локальную учётную запись.
В браузере: загрузка иллюстраций, фильтры игр, три языка, ширина 390px без горизонтальной прокрутки, редактирование через админку и появление правок на сайте.

## Границы демо

- Публичного адреса пока нет. localhost доступен только на этом компьютере. Не отправляйте его заказчику как внешнюю ссылку.
- ggplus.pro открывается отдельно, но во встроенном браузере Codex iframe остался на about:blank. Показан запасной путь. Авторизация на платформе не проверялась: нет тестовой учётной записи. Проверить iframe, cookie и вход в обычных браузерах на будущем HTTPS-домене; если провайдер ограничивает встраивание, согласовать его официально. Обход ограничений не реализован.
- Игровые карточки — демонстрационные изображения из предоставленного референса, открывают общий зал, а не конкретную игру. Нет встроенных ставок/платежей/балансов.
- Бонус и лимиты взяты из примеров; подтвердить перед публикацией. Нет вымышленных онлайн-счётчиков и выигрышей.
- Юридические сведения, оператор и окончательные условия ещё не предоставлены. В информационном окне это явно указано.
- Армянские тексты необходимо вычитать владельцу перед публичным запуском.
- Панель рассчитана на одного администратора и одну копию Node-сервера. Сессии в памяти истекают через 8 часов и теряются при перезапуске. Нет редактора структуры/добавления новых разделов.

## Следующий этап: размещение

Текущая сборка — React/Vite + Node/Express, требует Node-хостинг/VPS (не просто статический хостинг). Системный шаблон Sites отсутствовал в установленном плагине, поэтому использована самостоятельная локальная сборка. Публикация не выполнялась по запросу пользователя.

Для VPS: HTTPS reverse proxy, переменная PUBLIC_ORIGIN с точным HTTPS-origin, постоянный DATA_DIR, резервное копирование содержимого и uploads, секреты вне публичной директории, мониторинг процесса. Не публиковать data/admin-access.txt. При reverse proxy настроить доверенные proxy IP для корректного лимита попыток по клиентам; до этого лимит безопасно применяется к адресу proxy.
