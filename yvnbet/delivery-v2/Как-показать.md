# Показ заказчику

1. Откройте локальную главную: http://localhost:4173/ru.
2. На созвоне включите демонстрацию экрана: подтвердите возраст, покажите переключение слайдов, каталог, фильтр провайдера, язык и льва.
3. Откройте http://localhost:4173/admin и покажите редактирование слайда, провайдера и SEO. Данные для входа остаются прежними; не отправляйте пароль вместе со скриншотами.
4. Отправьте текст из «Сообщение-заказчику.txt» и согласуйте время демонстрации.

**localhost работает только на вашем компьютере.** Заказчику такую ссылку отправлять как публичный адрес нельзя. До размещения подходят созвон с демонстрацией экрана или скриншоты. Сервер и домен пока не менялись.

Сборка: `cd yvnbet && npm run build && npm start`. При обновлении сборки перезапустите сервер, чтобы он использовал новые файлы.
